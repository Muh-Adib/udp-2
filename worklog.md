# Worklog — Multi-Brand CRM (Grup Agensi Kreatif: Unimasi, Segia Tech, Erfo Multimedia, Unicam Studio)

## Konvensi desain (WAJIB diikuti semua agent)
- Stack: Next.js 16 App Router + TypeScript + Tailwind 4 + shadcn/ui (komponen ada di `src/components/ui`) + lucide-react + recharts + zustand + sonner (toast via `import { toast } from "sonner"`).
- DILARANG memakai warna indigo/blue sebagai warna utama. Aksen utama: zinc-900 untuk tombol primer, warna brand: Unimasi `#ea580c` (oranye), Segia Tech `#059669` (emerald), Erfo Multimedia `#e11d48` (rose), Unicam Studio `#7c3aed` (violet). Won = emerald, Lost = red-600, Nurture = slate, Hot = red-600, Warm = amber-500, Cold = cyan-600.
- Background halaman: `bg-zinc-100` (di luar area konten). Kartu: `rounded-xl border bg-white shadow-sm`, padding `p-4`/`p-6`, gap `gap-4`/`gap-6`.
- Semua list panjang: `max-h-96 overflow-y-auto` + custom scrollbar (`.crm-scroll` di globals.css).
- Ikon lucide-react saja. Font default Geist. Teks UI BAHASA INDONESIA.
- Setiap module adalah SATU file komponen client di `src/components/crm/` dengan signature: `export default function XModule()` (atau menerima props dari shell). Fetch data memakai `api` dari `@/lib/crm/api-client` dan store dari `@/lib/crm/store` (`useCrmStore` berisi user, brands, activeBrandFilter).
- Helper format: `formatCurrency, formatCurrencyFull, formatDate, formatDateTime, timeAgo, initials, parseJsonArray` dari `@/lib/crm/utils`. Konstanta pipeline/roles/channels: `@/lib/crm/constants` (PIPELINE_STAGES, stageLabel, stageColor, LOST_REASONS, NURTURE_SEGMENTS, CHANNELS, ROLES, BRAND_SERVICES, TEMPERATURES, PRIORITIES).
- Type data: `@/lib/crm/types` (OpportunityDTO, InteractionDTO, TaskDTO, dst).
- Responsive wajib: grid mobile-first (`grid-cols-1 sm:grid-cols-2 lg:grid-cols-4`), tabel → overflow-x-auto.
- JANGAN mengedit file milik agent lain: page.tsx, layout.tsx, globals.css, src/lib/**, src/app/api/** hanya milik main agent kecuali ditugaskan.

## Arsitektur
- Single page app: user hanya melihat route `/` (src/app/page.tsx) dengan navigasi state via zustand (`activeModule`). JANGAN membuat route halaman baru.
- API routes lengkap (sudah jalan & terverifikasi curl): bootstrap, auth/login, brands, users, dashboard, opportunities (+[id], +[id]/summary AI), contacts (+[id], +merge), companies, interactions, tasks (+[id]), projects, invoices (GET + add_payment), audit-logs, identify, inbox (+convert).
- DB: Prisma + SQLite `db/custom.db`, schema di `prisma/schema.prisma` — sudah di-push, sudah di-seed (4 brand, 7 user PIN 1234, 10 company, 12 contact, 21 opportunity semua stage, 5 raw lead inbox, task, note, 3 project + milestone, 5 invoice + payment, 5 template follow-up, audit log).
- Login demo: pilih persona → PIN `1234`. Role: super_admin, director, marketing, finance, production, client.

## API contract ringkas (response JSON)
- GET /api/dashboard → { kpi{totalLeads,openLeads,pipelineValue,weightedPipeline,winRate,wonValue,avgResponseHours,overdueTasks,unassignedLeads,outstandingInvoices}, funnel[{stage,count,value}], byBrand[{brandId,name,color,leads,won,value}], byChannel[{channel,count}], byCountry[{country,count}], forecast[{bucket,value}], lostReasons[{reason,count}], marketingPerf[{name,leads,won,avgResponseHours}], recentAudit[...], pipelineTrend[{label,created,won}], projectsAtRisk, productionCapacity }
- GET /api/opportunities?stage&brandId&q&owner → { opportunities: OpportunityDTO[] (include brand, contact{company}, company) }
- GET /api/opportunities/:id → { opportunity (include interactions[], tasks[], notes[], projects[milestones], invoices), related[] }
- PATCH /api/opportunities/:id body { ...fields, actorName, actorRole } → stage change ternormalisasi + audit log; stage=won auto-buat project+milestone+invoice DP; stage=lost wajib lostReason → 400 jika kosong
- POST /api/inbox/convert body { interactionId, action:"link"|"new", contactId?, contact?, opportunity{brandId,title,...}, actorName }
- GET /api/inbox → { leads: InteractionDTO & { slaHours, candidates[] } }
- POST /api/identify body { email?, whatsapp?, fullName?, companyName? } → { candidates[{contactId,score,reasons[],contact}] }
- POST /api/contacts/merge body { primaryId, duplicateId, actorName }
